# Trainer artwork

These unmodified PNGs depict generic trainer classes from Pokémon Omega Ruby and Alpha Sapphire. They are used for actor portraits and matching Foundry token textures. No named story characters, protagonists, Gym Leaders, or anime characters are in the generator's artwork pool.

- [Ace Trainer, female](https://archives.bulbagarden.net/wiki/File:ORAS_Ace_Trainer_F.png) — Ken Sugimori.
- [Ace Trainer, male](https://archives.bulbagarden.net/wiki/File:ORAS_Ace_Trainer_M.png) — Ken Sugimori.
- [Lass](https://archives.bulbagarden.net/wiki/File:ORAS_Lass.png).

Source: Bulbagarden Archives. Original Pokémon artwork belongs to Nintendo, Creatures, and GAME FREAK. The Archives identify these files as game images used under fair use; the module's MIT license applies to original module code and does not license this artwork. Each generated trainer retains the source link in its module flags and preview.
